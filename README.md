# Интернет-магазин (Django проект)

Учебный проект на Django, реализующий простую структуру интернет-магазина.

## Функционал

- Главная страница (`/`)
- Страница контактов (`/contacts/`)
- Приложение `catalog` с базовыми шаблонами
